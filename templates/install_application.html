Safari sur iPhone

Ajouter à l’écran d’accueil en trois étapes

Ouvre runningdataplan.com avec Safari, puis suis les écrans ci-dessous.

Étape 1

Ouvre le menu Safari

Appuie sur le bouton avec les trois points, à droite de la barre d’adresse.

Étape 2

Choisis « Partager »

Dans le menu qui apparaît, appuie sur l’option Partager.

Étape 3

Ajoute sur l’écran d’accueil

Fais défiler les actions puis sélectionne « Sur l’écran d’accueil » et confirme.

À savoir : si l’option n’apparaît pas, vérifie que la page est bien ouverte dans Safari, et non dans le navigateur intégré d’une autre application. Une fois installée, l’icône ouvrira directement la page d’accueil de Running Data Plan, pas cette notice.
▶

Chrome sur Android

Créer le raccourci Running Data Plan

Le libellé exact peut varier légèrement selon la version de Chrome et le téléphone.

Ouvre runningdataplan.com dans Chrome.
Appuie sur le menu ⋮ en haut à droite.
Choisis Ajouter à l’écran d’accueil ou Installer l’application, puis confirme.
Running Data Plan reste une application web : la synchronisation des activités Strava et des données CGM nécessite une connexion Internet.

Ton accès est prêt

L’icône ouvre directement Running Data Plan. Connecte-toi avec ton compte habituel.
